# 选型决策表 — 数据情形 → 图型 → 推荐案例

> 机器优先：选图先跑 `python scripts/route.py "<用户意图>" --n 9 --log`（场景路由器，逐图档案在
> `reference/routing/`）。本表是人读的决策兜底：路由结果的合理性与"数据情形→图型"的语义都在这里。

用法定位：先找"数据情形"，取推荐 seg 编号，参考图在 `gallery/case_segNNN.png`，配方在 `scripts/recipes/case_segNNN.py`，完整视觉要点在 `catalog.json` 对应条目的 `features` 字段。

## 0. 高级感速查（用户说"要高级/惊艳/顶刊范"时从这里起手）

`wow` 分级（catalog.json `wow` 字段，1=常规扎实 · 2=有设计感 · 3=镇场级，共 32 张 3 级）。
起手直接摆跨家族 wow 样板册，再按想要的惊艳点收窄：

```bash
python scripts/make_contact_sheet.py sheet --out /tmp/wow.png --min-wow 3 --sample 9 --open
```

| 想要的惊艳点 | wow=3 案例 |
|---|---|
| 环形/放射结构 | 012-015 发育树圈图、048 多环参与者、092/093 半圆小提琴/扇形箱线、100/101 环状条形、139 内向环形堆叠 |
| 流向/关系网络 | 027 和弦图、035 circos 弦+富集网络、045/046 多层桑基、091 冲击图、089 热图+Mantel 网络 |
| 空间/3D | 051-053 世界地图+饼、117 中国地图、143 3D 双层地图、059 地图+雷达内嵌 |
| 分布的山峦感 | 016 分组山脊、032 山脊+侧边条形 |
| 高维双编码/复合 | 133 环形热图+UpSet、134 UMAP+环形注释、127-129 三元气泡/密度、135 双曲线边界火山、056 放射状网络气泡、074 复合哑铃面板 |

**wow ≠ 合适**：数据撑不起复杂结构（三元和不为 100%、桑基层级缺失、环形图类别太少、
地图没有地理字段）就退一档，向用户说明原因。朴素而正确的图好过惊艳而错误的图。
